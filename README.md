# MPatch · 原型圈改工具

一个 macOS 桌面 MVP：打开本地 HTML 原型，在页面上选择、圈选或涂抹目标区域，用自然语言记录需求，并生成精简的开发 Prompt。

## 启动

```bash
npm install
npm start
```

首次安装会下载 Electron 桌面运行时。应用启动后，点击“打开 HTML 原型”并选择项目的入口 HTML 文件；该文件同目录及子目录中的相对 CSS、图片和脚本会按原路径加载。

## 当前能力

- 点选真实 DOM 元素，自动记录选择器、原始文本和局部 HTML；
- 圈选、涂抹和指定插入位置；
- 用自然语言描述修改、插入、删除或整体优化需求；
- 将多个需求编译成低 Token 的紧凑 Prompt；
- 可选复制“增强上下文版”，仅在模型无法定位时补充局部 HTML；
- 保存和恢复 `.mpatch.json` 标注会话；
- 桌面 / 手机预览宽度切换。

## Prompt 策略

默认版本不会输出完整页面源码、完整 CSS、全量 computed style 或重复约束。它按以下格式组织：

```text
修改 `index.html`。全局：未标注区域不变；沿用现有设计语言；兼容桌面端和移动端；不引入新框架。

[M1] .hero > h1；当前="产品标题"
需求=让标题更突出，但保持高级克制，避免促销感。
```

当目标没有可靠 selector、存在大量同类元素，或模型第一次修改失败时，再选择“复制增强上下文版”。

## 注意

这是一个本地原型审阅工具，应用不会直接覆盖被打开的 HTML 文件；它只保存标注会话和生成 Prompt。
